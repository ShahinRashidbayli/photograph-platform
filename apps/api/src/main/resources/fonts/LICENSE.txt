DejaVu Sans — bundled fonts
===========================

DejaVuSans.ttf and DejaVuSans-Bold.ttf are redistributed with this
application. They are embedded into every generated invoice PDF by
InvoicePdfRenderer.

Why they are vendored rather than taken from the host: PDF's built-in base-14
fonts are not embedded and cannot encode umlauts, ß or €, so openhtmltopdf
silently dropped every text run containing them — see the javadoc on
InvoicePdfRenderer. Resolving a font from the operating system instead would
make the rendered document depend on which fonts a machine or base image
happens to carry.
